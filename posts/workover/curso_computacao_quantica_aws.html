Objetivo:

Utilizar serviços de computação quântica da AWS (Braket) para desenvolver aplicações que aproveitem os benefícios da computação quântica e híbrida em ambientes cloud.


Pré-requisitos:

  • Conhecimento básico de Python e Qiskit;
  • VSCode com extensões Python e Django;
  • Conta gratuita na AWS.

Introdução:

Amazon Braket é serviço da AWS para utilização de dispositivos e desenvolvimento de circuitos quânticos (QPUs). Compõe-se de notebooks para ambiente de desenvolvimento, trabalhos híbridos e tarefas quânticas, bibliotecas contendo principais algoritmos e dispositivos (Braket Direct) quânticos do mercado. Para utilizar AWS Braket, crie perfil com regras (roles) adequadas, seguindo instruções no painel do AWS Braket Console.
